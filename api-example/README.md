# API Examples

Front-end examples that consume REST APIs with the Fetch API, from simple data display to full create, read, update, and delete (CRUD) operations.

## Examples

| Folder | Description |
| ------ | ----------- |
| [courses](./courses) | Fetches courses from the Courses REST API and displays them on the page |
| [courses-card](./courses-card) | Displays course data as cards |
| [courses-modal](./courses-modal) | Shows course details in a modal dialog |
| [coursesCRUD](./courses-crud) | Creates, reads, updates, and deletes courses using `POST`, `PUT`, and `DELETE` requests |
| [weather-api](./weather-api) | Fetches and displays weather data from a public weather API |

## Running the Examples

The course examples fetch data from the local Courses REST API built in Workbook 7. Start that server first, then open the example's `index.html` in a browser.

The `weather-api` example calls a public API, so it only needs an internet connection.
