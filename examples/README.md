# Examples

Small front-end examples of common UI patterns, including form controls, dropdowns, tables, and Bootstrap components, built with vanilla JavaScript.

**Stack:** HTML · CSS · Bootstrap · JavaScript

## Contents

| Folder | Description |
| ------ | ----------- |
| [bootstrap-card](./bootstrap-card) | Displays content in Bootstrap cards |
| [buttonSelect-dropdown](./buttonSelect-dropdown) | Uses a button to select an option in a dropdown |
| [dropdown-select](./dropdown-select) | Loads a `select` dropdown and responds to the selected option |
| [multi-select-dropdown](./multi-select-dropdown) | Handles a `select` that allows multiple selections |
| [orderForm-submission](./orderForm-submission) | Collects order details in a form and handles submission |
| [table-list](./table-list) | Builds a table dynamically from a list of data |
