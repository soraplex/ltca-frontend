# Web Development Workbooks

Coursework from a full-stack web development program, covering front-end fundamentals, client-server communication, and relational databases. Originally nine separate repositories, consolidated here into one.

**Stack:** HTML · CSS · Bootstrap · JavaScript · Node.js · SQL (plus introductory Python and Java)

## Contents

### Front-End Fundamentals

- **[Workbook 1](./workbook1):** HTML, CSS, Bootstrap
- **[Workbook 2](./workbook2):** Vanilla JavaScript, conditional statements, event handling
- **[Workbook 3](./workbook3):** Functions, return values, scoping, strings, dates, forms
- **[Workbook 4](./workbook4):** Objects, loops and arrays, forms
- **[Workbook 5](./workbook5):** Arrays, DOM and BOM, modifying page content, tables

### Algorithms

- **[Workbook 6](./workbook6):** Codewars practice, algorithms, introductory Python and Java

### Client-Server and Data

- **[Workbook 7](./workbook7):** JSON, AJAX (REST APIs), Postman, Fetch API, CORS, Node.js
- **[Workbook 8](./workbook8):** HTTP methods, Fetch API, Web Storage
- **[Workbook 9](./workbook9):** OOP in JavaScript, SQL, relational databases, querying data

## Running the Projects

Front-end exercises can be opened directly in a browser. Node.js exercises run with:

    node <filename>.js
